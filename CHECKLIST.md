# Checklist de entrega - Simulador MRN

## Requisitos funcionais

- [x] RF01 - Registradores dinâmicos por letra maiúscula e valores `bigint` em N.
- [x] RF01 - Decremento protegido: zero nunca sofre underflow.
- [x] RF02 - Interpretador das primitivas `INC`, `DEC` e `TST` com rótulos.
- [x] RF03 - Compilação de `ZER R`, soma preservativa e subtração monótona.
- [x] RF03 - Compilação de multiplicação por somas sucessivas.
- [x] RF03 - Compilação da divisão inteira e do resto.
- [x] RF04 - GUI Vue com editor, execução, passo a passo, IP e registradores.
- [x] RF04 - Importação de arquivos `.norma` e `.txt`.
- [x] RF04 - Limite configurável de ciclos e alerta de interrupção.

## Qualidade e entrega

- [x] Testes automatizados de primitivas e TC-01 a TC-03.
- [x] Teste automatizado TC-04.
- [x] Execução de todos os testes automatizados.
- [x] Build de produção para Vercel.
- [x] README com instalação, sintaxe e roteiro de demonstração.
- [x] Relatório técnico-base: arquitetura, registradores, grafos, procedimentos e tabela de evidências.
- [ ] Preencher integrantes/RA e resultados observados no relatório antes da entrega.
